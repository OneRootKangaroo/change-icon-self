# change-icon-self

在 vivo / iQOO（OriginOS）上，不换主题、不刷机，把桌面图标批量换成自己的图片。

<br />

## 效果图

![桌面效果图](docs/screenshot.jpg)

## 用法

1- 首次使用运行install.sh

2- 图片文件放到icon文件夹内，命名规则：QQ.jpg，微信.png

3- 运行push\_icons.sh，mac用户也可双击「应用自定义图标.command」

<br />

注意：

电话/联系人这种同包名双入口的，请将手机上app图标从duck栏拖到桌面上，才能看到名字。这种app是同一个，但是是用不同的包名来启动不同的activity。
